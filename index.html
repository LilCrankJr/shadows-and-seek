The game

The candles are lit.
Something in the ballroom just moved.

Shadows & Seek is a hide-and-seek game set in a sprawling palace of checkered halls, velvet salons and flickering candelabras. One side hunts. The other side hides in plain sight, slips between rooms and lights the old shrines before the clock runs out.

The Seekers

Sweep the palace room by room, read the shadows and catch every Hider before time runs out.

The Hiders

Blend into the décor, steady your hand at the shrines and slip away before the Seekers close in.

What's inside

Built for one more round

A whole palace to haunt

Three floors of grand halls, galleries, a chapel, archives, servants' passages and secret corners. Learn the routes and the hiding spots.

First-person option

Play over-the-shoulder, or switch to first person for a tighter, scarier view of every dark doorway.

Controller support

Plug in an Xbox-style gamepad and play from the couch, with on-screen button prompts that match your pad. Mouse and keyboard work too.

Candle & shrine skill checks

Lighting a candle or a shrine takes a steady hand. Hit the timing window and the flame catches. Fumble it and you lose precious seconds while the Seekers close in.

Install

Up and running in four steps

  1. Download the release files

    From the release page, under Assets, download the .zip. If the build is split into several files (….zip.part001, .part002, …), download all of the parts and join-parts.cmd into the same folder.

  2. Join the parts (split downloads only)

    Double-click join-parts.cmd. It stitches the parts back into one .zip. Skip this step if you downloaded a single zip.

  3. Unzip and run

    Right-click the zip, choose Extract All…, and pick a folder with about 10 GB free. Open the extracted folder and run the game's .exe.

  4. Get past SmartScreen

    The beta isn't code-signed yet, so Windows may show a blue "Windows protected your PC" box the first time. That's expected:

System requirements

OS
Windows 10 or 11, 64-bit
Graphics
DirectX 12-capable GPU with up-to-date drivers
Storage
~10 GB free disk space
Input
Mouse & keyboard or Xbox-style controller

Running slowly? Lower the graphics quality in Settings. Windows only for now; there are no Mac or Linux builds yet.

Controller vs bots? Double-click Play with controller (offline).cmd next to the game's .exe: it starts without Steam, so the pad works at once (offline practice only).

Controller not responding online? In Steam: Library > Spacewar > Properties > Controller > Disable Steam Input, then restart the game.

Found a bug in the dark?

This is a beta, so things will break. Use the bug-report screen in the game's menu, or open an issue on GitHub with what happened, what you expected and your PC specs. Screenshots help a lot.
